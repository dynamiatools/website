El stack frontend de Dynamia Platform ahora sigue un **enfoque modular**:

1. **SDK core**: `@dynamia-tools/sdk`
2. **Adaptador UI (beta)**: `@dynamia-tools/vue`
3. **SDKs de extensiones** cuando tu backend habilita modulos extra (`reports`, `entity-files`, `saas`)

Esta pagina resume el nuevo enfoque y como combinar estos paquetes.

## Stack Frontend (v26)

### 1) SDK core (`@dynamia-tools/sdk`)

El SDK core siempre es la base. Te da acceso tipado a metadata, navegacion, CRUD y acciones.

```bash
pnpm add @dynamia-tools/sdk
```

```typescript
import { DynamiaClient } from '@dynamia-tools/sdk';

export const client = new DynamiaClient({
  baseUrl: import.meta.env.VITE_API_URL,
  token: localStorage.getItem('auth_token') ?? undefined,
});
```

### 2) Soporte Vue (`@dynamia-tools/vue`) - Beta

Si construyes en Vue 3, usa el adaptador oficial.

```bash
pnpm add vue @dynamia-tools/vue @dynamia-tools/ui-core @dynamia-tools/sdk
```

Consulta la guia dedicada: [Vue Support (Beta)](/es/vue-support).

### 3) SDKs de extensiones (opcional)

Instala estos paquetes solo cuando tu backend usa la extension correspondiente:

- `@dynamia-tools/reports-sdk`
- `@dynamia-tools/files-sdk`
- `@dynamia-tools/saas-sdk`

Consulta [Extensiones](/es/extensions/) para instalacion y uso por extension.

## Arquitectura Recomendada

Usa un unico `DynamiaClient` compartido y pasa `client.http` a los SDKs de extensiones.

```typescript
import { DynamiaClient } from '@dynamia-tools/sdk';
import { ReportsApi } from '@dynamia-tools/reports-sdk';
import { FilesApi } from '@dynamia-tools/files-sdk';
import { SaasApi } from '@dynamia-tools/saas-sdk';

const client = new DynamiaClient({
  baseUrl: import.meta.env.VITE_API_URL,
  token: localStorage.getItem('auth_token') ?? undefined,
});

export const reports = new ReportsApi(client.http);
export const files = new FilesApi(client.http);
export const saas = new SaasApi(client.http);
```

## Capacidades Core en el Nuevo Flujo

### Metadata y navegacion

```typescript
const app = await client.metadata.getApp();
const navigation = await client.metadata.getNavigation();
console.log(app.name, navigation.navigation.length);
```

### CRUD por ruta virtual

```typescript
const booksApi = client.crud('library/books');
const page = await booksApi.findAll({ page: 1, size: 20, q: 'clean code' });
```

### Filtrar, buscar y ordenar con `find()`

`findAll()` solo lee `page`, `size`, la búsqueda de texto `q` y el orden. Para filtrar por campo usa `find()`: envía un `QuerySpec` a `POST /api/{path}/find` y devuelve el mismo `CrudListResult<T>`.

```typescript
const result = await client.crud('library/books').find({
  filters: [
    { field: 'publishDate', op: 'between', value: ['2026-01-01', '2026-01-31'] },
    { field: 'status', op: 'in', value: ['AVAILABLE', 'RESERVED'] },
  ],
  search: 'clean',                 // búsqueda de texto en los campos de texto visibles
  sort: [{ field: 'title', dir: 'asc' }],
  page: 1,                         // base 1
  size: 20,
});
```

Un `QuerySpec` tiene estas partes (todas opcionales):

| Campo | Significado |
|---|---|
| `filters` | Lista de `{ field, op, value }`, máximo uno por campo |
| `search` | Texto a buscar en los campos de texto visibles |
| `sort` | Lista de `{ field, dir }`; `dir` es `asc` (por defecto) o `desc` |
| `page` / `size` | Página (base 1) y tamaño de página |

Operadores: `eq`, `like`, `between` (`[desde, hasta]`, un lado `null` queda abierto), `gte`, `lte`, `in` (una lista) e `isNull` (un booleano). Una fecha sin hora cubre todo el día de un campo que tiene hora.

El servidor valida cada campo contra el descriptor de vista de la página. Un campo que el descriptor no tiene, un valor de tipo incorrecto o una consulta que supera los límites se rechaza con un `422` (`DynamiaApiError`), nunca se ignora en silencio. Los límites son 20 filtros, 100 valores en un `in`, 5 claves de orden, 200 caracteres de búsqueda y un tamaño de página de 500 (50 por defecto).

`POST /api/{path}/find` y `crud(path).find()` están disponibles desde Dynamia Platform **26.11.0**. Para restringir en el servidor lo que un cliente puede consultar, registra un bean `QuerySpecFilter`; consulta [Filtros y consultas de listas](/es/guides/list-filters#filtros-de-consulta-en-el-servidor).

```typescript
await client.actions.executeGlobal('exportBooksToExcel', {

```

## Autenticacion

El mismo modelo de auth se reutiliza en todos los paquetes frontend mediante el mismo `HttpClient`:

- `token` para Bearer (recomendado para SPA)
- `username` + `password` para Basic auth
- `withCredentials: true` para auth por cookies/sesion

## Manejo de errores

```typescript
import { DynamiaApiError } from '@dynamia-tools/sdk';

try {
  await client.crud('library/books').findById(999999);
} catch (error) {
  if (error instanceof DynamiaApiError) {
    console.error(`[${error.status}] ${error.message}`);
  }
}
```
