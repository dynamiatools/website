Cada pantalla que DynamiaTools genera automáticamente a partir de un [descriptor de vista](/es/view-descriptors) — formularios, tablas, la barra de navegación, la pantalla de login — se renderiza dentro de una **plantilla (template)**: una dependencia Maven/Gradle que provee el shell HTML, el CSS y los componentes ZK alrededor de tu contenido. Cambiar la plantilla cambia el aspecto de toda la aplicación sin tocar un solo descriptor de vista ni entidad.

<Aside type="note" title="Un solo tema por ahora">
  El sistema de plantillas es conectable por diseño, pero **`theme-dynamical` es actualmente el único tema que Dynamia Platform incluye**. Todavía no hay una galería de temas alternativos entre los cuales elegir — piensa en esta página como la documentación de la implementación de referencia, no como una elección entre opciones.
</Aside>

## Cómo funciona la selección de plantilla

Una plantilla se selecciona con dos propiedades de Spring Boot bajo el prefijo `dynamia.app` — el mismo grupo de propiedades que usa la [guía de Comenzando](/es/getting-started) para `name`, `default-logo` y similares:

```yaml
# application.yml
dynamia:
  app:
    template: Dynamical
    default-skin: Blue
```

- **`dynamia.app.template`** — el nombre del bean de plantilla instalado (`Dynamical` para `theme-dynamical`)
- **`dynamia.app.default-skin`** — qué skin de color renderiza la plantilla por defecto

Nada más en tu aplicación cambia: las entidades, los `ModuleProvider` y los descriptores de vista son agnósticos a la plantilla. La plantilla solo controla el layout, el CSS y el "chrome" alrededor de tus páginas.

## theme-dynamical

`theme-dynamical` es la plantilla de referencia (y, por ahora, la única) de Dynamia Platform. Está construida sobre [AdminLTE](https://adminlte.io/) — una plantilla de panel de administración gratuita con licencia MIT — corriendo sobre **Bootstrap 5** y optimizada específicamente para **ZK 10.x**.

### Instalación

**Maven**

```xml
<dependency>
  <groupId>tools.dynamia.themes</groupId>
  <artifactId>tools.dynamia.themes.dynamical</artifactId>
  <version>5.4.0</version>
</dependency>
```

**Gradle**

```groovy
compile 'tools.dynamia.themes:tools.dynamia.themes.dynamical:5.4.0'
```

<Aside type="tip">
  Los proyectos generados con el <a href="/es/ecosystem/cli">CLI</a> (`dynamia new`) ya incluyen `theme-dynamical` en el classpath — solo necesitas agregar esta dependencia manualmente si partiste de un proyecto Spring Initializr sencillo, según la guía de <a href="/es/getting-started">Comenzando</a>.
</Aside>

### Configuración

```yaml
# application.yml
dynamia:
  app:
    template: Dynamical
    default-skin: Blue
```

O en `application.properties`:

```properties
dynamia.app.template=Dynamical
dynamia.app.default-skin=Blue
```

### Skins disponibles

Establece `default-skin` con cualquiera de estos valores:

- Blue
- Dynamia
- Red
- Orange
- Purple
- Green
- DarkOrange
- Yellow
- Olive
- Black

Cambiar el skin es un cambio puramente de configuración — no hay CSS que escribir, ni rebuild de la plantilla misma.
