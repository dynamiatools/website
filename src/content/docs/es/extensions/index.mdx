Esta seccion documenta las extensiones oficiales de Dynamia Platform y como integrarlas en:

- proyectos backend (Maven/Gradle),
- aplicaciones frontend (paquetes Node), cuando aplique.

## Extensiones disponibles

- [Dashboard](/es/extensions/dashboard/)
- [Email y SMS](/es/extensions/email-sms/)
- [Entity Files](/es/extensions/entity-files/)
- [File Importer](/es/extensions/file-importer/)
- [Finances](/es/extensions/finances/)
- [HTTP Functions](/es/extensions/http-functions/)
- [Reports](/es/extensions/reports/)
- [SaaS](/es/extensions/saas/)
- [Security](/es/extensions/security/)

## Nota de version

Los ejemplos usan `{dynamiaToolsVersion}` porque es la version actualmente referenciada en este monorepo.

Si tu proyecto centraliza la version de Dynamia, reemplaza valores hardcodeados por tu propiedad de version.
